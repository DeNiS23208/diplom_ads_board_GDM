Diplom Ads Board GDM

📌 Описание проекта

Дипломный проект представляет собой сервис объявлений, реализованный на
Django + DRF.
Функционал включает регистрацию пользователей, категории объявлений,
CRUD для объявлений, фильтрацию, поиск, систему прав доступа и
модерацию.

------------------------------------------------------------------------

🚀 Функционал

-   Регистрация и аутентификация пользователей (JWT)
-   CRUD для объявлений и категорий
-   Фильтрация, поиск и сортировка
-   Права доступа:
    -   автор может редактировать/удалять свои объявления
    -   админ может модерировать объявления (публиковать, архивировать,
        отклонять)
-   API-документация через drf-spectacular
-   Тестирование (pytest, pytest-django, pytest-cov)
-   Контейнеризация с помощью Docker Compose
-   Настроенный CORS для фронтенда

------------------------------------------------------------------------

🛠️ Технологии

-   Python 3.12
-   Django 5
-   Django REST Framework
-   drf-spectacular
-   PostgreSQL
-   Docker + Docker Compose
-   pytest + pytest-cov
-   django-filter
-   CORS Headers

📂 Установка и запуск

1. Клонирование репозитория

    git clone https://github.com/DeNiS23208/diplom_ads_board_GDM.git
    cd diplom_ads_board_GDM

2. Создать и заполнить .env на основе шаблона

В проекте есть файл .env.template, скопируйте его:

    cp .env.template .env

Укажите свои данные (например, POSTGRES_USER, POSTGRES_PASSWORD,
SECRET_KEY и т. д.).

3. Запуск через Docker Compose

    docker compose up --build

После запуска: - Backend будет доступен на: http://localhost:8000/api/ -
Swagger-документация: http://localhost:8000/api/schema/swagger-ui/ -
Redoc-документация: http://localhost:8000/api/schema/redoc/

------------------------------------------------------------------------

🔑 Пользователи и права

-   Неавторизованные — могут только просматривать объявления и
    категории.
-   Авторизованные — могут создавать объявления, редактировать и удалять
    только свои.
-   Администраторы — могут модерировать объявления (опубликовать,
    отклонить, архивировать).

------------------------------------------------------------------------

🧪 Тестирование

Запуск тестов

    docker compose exec web pytest -q

Запуск с покрытием

    docker compose exec web pytest --cov=ads --cov-report=term-missing -q

------------------------------------------------------------------------

🔗 CORS

Для работы с фронтендом настроен django-cors-headers.
Это позволяет обращаться к API с другого домена (например, с React или
Vue приложения).

В settings.py добавлены:

    INSTALLED_APPS = [
        ...
        "corsheaders",
    ]

    MIDDLEWARE = [
        "corsheaders.middleware.CorsMiddleware",
        ...
    ]

    CORS_ALLOW_ALL_ORIGINS = True  # в продакшене заменить на белый список
